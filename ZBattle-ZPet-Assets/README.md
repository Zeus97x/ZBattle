# ZBattle — copied ZPet creature collection

Copied from ZPet-Coding-Checkpoint-2026-10-08.zip on 2026-10-08.

Includes all 54 existing monster PNGs unchanged, plus creature catalogs, journal, region catalog and the original CreatureView rendering reference. The catalogs define 12 families, 72 named forms, and 48 species variants. Variants reuse family artwork. There are not separate PNGs for every catalog entry; rendering reference is included to preserve the available implementation. Reference Java files retain their original ZPet package and dependencies and are not a standalone ZBattle implementation.

This is a reusable design/reference collection, not a transfer of live player saves. ZPet remains unchanged. ZBattle development remains deferred until ZPet is finished. Planned player imports are one-way ZPet to ZBattle; battle progress must never return to ZPet.
